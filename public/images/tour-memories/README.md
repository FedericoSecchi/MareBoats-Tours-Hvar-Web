# Tour Memories gallery

Drop photos here and the gallery at `/hvar-boat-tour-photos/` renders them automatically on the next build. Empty folder = gallery section does not render.

## Format
- `.webp` (preferred) or `.jpg`
- Recommended width: 1600 px on the long edge
- Maximum file size: 400 KB per image

## Naming convention
`tour-memories-YYYY-MM-DD-nn.webp`

Examples:
- `tour-memories-2026-07-14-01.webp`
- `tour-memories-2026-08-02-03.jpg`

Files sort alphabetically, so the naming convention doubles as the display order.

## Privacy
Only upload photos where guests gave permission or faces are not recognizable.
